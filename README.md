# ASN Processing Result API Documentation

Public integration documentation for the Business Central `asnProcessingResults` endpoint.

The published site explains:

- the boundary between file validation and downstream ASN processing;
- how `asnValidationRequests.id` becomes `sourceRequestId`;
- the recommended SRM polling flow;
- stable processing states, failure stages, and error handling;
- request and response examples without credentials or tenant-specific identifiers.

The site is published automatically through GitHub Pages.
